# UX-ревью Луча: для человека, который ничего не знает о технике

Что смотрели: расширение GNOME (`gnome-extension/`), приложение в строке меню Mac (`macos/Sources/LuchApp`),
экраны приёмника на ТВ и телефоне (`luch-android`: `StatusActivity`, карточка `PairPrompt`, плеер), сообщения
`luchctl`. Критерии: меньше нажатий, понятно с первого взгляда, видно «что сейчас происходит», ошибка говорит, что
делать, одинаковые слова на GNOME, Mac и ТВ, первый запуск, управление пультом.

Не входит сюда: совместный показ на несколько ТВ (группы, «Play Together», звук и синхронизация в меню ТВ, Latency
Lab) — это владелец A; «Показать файл/ссылку» и меню «Поделиться»/контекстные меню — владелец D. Замечания по ним
в конце, для них.

Ещё сделано по пути:

- GNOME: нажатие на саму плитку при ошибке молчало (только в журнал), а после ввода кода не продолжало показ.
  Теперь ошибка показывается, а после сопряжения показ начинается сам, как из меню.
- GNOME: ошибка «Включить …» (Wake) теперь показывается, не только пишется в журнал.
- Mac: у всех ТВ в списке есть значок (раньше только у первого), у браузера — глобус.
- Mac: уведомление «почему остановилось» («Stopped on the TV», «Stopped: macOS ended the screen recording …»)
  показывается один раз, после закрытия меню список снова чистый; остановка из меню — без уведомления.
- Подсказка «на ТВ выберите „Сказать адрес“» не совпадала с кнопкой ТВ «Сказать адрес звуком» / «Say the address
  by sound» — исправлено в GNOME, Mac (`Ladder.swift`) и luchd (`find/mod.rs`).
- ТВ: «Забыть сопряжённые компьютеры (N)» стирало всё одним нажатием OK на пульте. Теперь спрашивает, фокус на
  «Отмена».
- ТВ: строка «Проверить детектор калибровки синхронизации на синтезированной записи» в настройках у всех — только в
  отладочной сборке (`BuildConfig.DEBUG`). *Это часть синхронизации (владелец A): одна строка, см. отчёт.*
- `luchctl`: «(is luchd running?)» → с командой запуска; «no receivers found (is the receiver app running?)» →
  «open Luch on the TV, or try `luchctl find`»; на Mac «Luch.app is not running» → «start it with `open -a Luch`».

## Приёмник (ТВ, телефон)

Хорошо уже сейчас: крупный «Готов принимать», QR-код по нажатию, «Сказать адрес звуком», карточка сопряжения в
углу с фокусом на «Разрешить» (на старом Луче без шифрования — на «Отклонить»), «Назад» дважды для остановки,
первый D-pad не теряется (скролл не берёт фокус).

Сделано: словарь в `values-ru` («приёмник», «показ», «Луч»), подтверждение «Забыть запомненные компьютеры», проверка
детектора калибровки — только в отладочной сборке.

Осталось (позже):

- На главном экране ТВ чип «Wi-Fi, порт 47800» — порт нужен только для ручного добавления; лучше показывать его на
  экране QR-кода.
- Вкладка «Отправка» на ТВ почти не нужна (ТВ редко показывает свой экран): на ТВ её можно спрятать за настройками.
- Переключатель «Гостевой режим: забывать компьютеры при выключении» — длинная строка без пояснения, кому он нужен.

## Осталось на потом

1. **Mac не переведён на русский.** GNOME и ТВ двуязычные, Mac — только английский. Нужен String Catalog
   (`Localizable.xcstrings`) и перевод по словарю выше; сейчас слова Mac согласованы с английскими GNOME и ТВ.
2. Подменю ТВ на Mac всё ещё ~20 строк. Предложение: «Show As ▸», «Sound ▸» и Latency Lab (владелец A) собрать в
   одно «Picture & Sound ▸», а «Allow TV to Control This Mac» — в Settings.
3. «Find Receivers ▸» на Mac: шесть способов поиска на одном уровне («Ask Every Address of This Network», «Listen
   over Bluetooth»…). Оставить «Search Again» и «Search Harder», остальное — под «Other Ways».
4. Ошибки luchd по-прежнему приходят по-английски; `plain.js`/`Plain.swift` переводят известные. Правильнее, чтобы
   luchd отдавал код беды (`{"kind": "unreachable", "detail": …}`), а слова были только в интерфейсах.
5. Первый запуск на Mac: приветственное окно «1) откройте Луч на ТВ, 2) разрешите запись экрана» до первого
   показа, а не после отказа.

### Для владельца A (группы)

- GNOME: меню групп добавлять в `_render` после строк ТВ и до «Ещё»; ошибки — через `tell()` (`plain.js`), слова —
  по словарю («показ», «приёмник»); «cannot play in step yet: update it» уже распознаётся (`update`),
  «{name} is not connected» и «{name} is busy» групп — нет / как `busy`: проверьте, что слова подходят.
- Mac: «Sound: …», «Latency Lab», сдвиг — на первом уровне подменю ТВ; Latency Lab — инструмент разработчика, ему
  место в Settings ▸ Advanced или под Option.
- ТВ: строка проверки детектора калибровки теперь только в отладочной сборке (`StatusActivity.settingsCard`).

### Для владельца D (файлы)

- «Close what is shown» / «Закрыть показанное» переименовано в «Убрать файл с экрана ТВ» / «Stop showing the file»
  (GNOME `stopCast`); на Mac — «Stop Showing». «Show Link from Clipboard» неактивен без ссылки и не объясняет
  почему — стоит подсказка «Copy a link first».
